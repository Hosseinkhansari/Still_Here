Still Here

A Stranger Things fan page created to bring together some of the moments, quotes, music, and scenes that make the show memorable.

The project focuses on presenting the atmosphere of Stranger Things through a simple and visually themed webpage.

Features

* Memorable Quotes: A collection of memorable quotes from the series.
* Image Gallery: A selection of images from Stranger Things.
* Soundtracks: Audio players featuring music associated with the show.
* Video Edits: A collection of video edits related to the series.
* Simple Navigation: Jump between different sections of the page.
* Responsive Design: A layout designed to work on different screen sizes.

Technologies Used

* HTML5
* CSS3

Project Structure

* index.html — Main page and project content.
* ST.css — Styles and visual design.
* images/ — Images used in the gallery.
* media/ — Audio and video files.

Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.

You can also use the Live Server extension in Visual Studio Code.
